# Data Source

`movies.csv` contains 250 plots from the [CMU Movie Summary Corpus](https://www.cs.cmu.edu/~ark/personas/), collected by David Bamman, Brendan O'Connor, and Noah A. Smith. Plot text is by Wikipedia contributors.

The subset uses the first 250 nonempty plots whose Wikipedia page IDs still resolve. Plot wording is unchanged; current Wikipedia titles were added on November 20, 2026, and records were saved as CSV. The app splits plots into 80-word passages.

The data and plot passages retain the [Creative Commons Attribution-ShareAlike 3.0 US license](https://creativecommons.org/licenses/by-sa/3.0/us/). Each search result links to its Wikipedia source.
